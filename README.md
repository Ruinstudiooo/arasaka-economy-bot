# arasaka-economy-bot

Discord economy bot with an Arasaka corporate theme.

## Commands

- `/balance` — check your eddy balance
- `/daily` — claim your daily payout
- `/work` — pull an Arasaka shift for eddies
- `/pay` — transfer eddies to another employee
- `/leaderboard` — top earners in the corp

## Install

Paste the plugin folder URL into Revenge. Built with Vendetta.
